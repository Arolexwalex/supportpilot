Nimbus Features and Usage Guide

Sharing files and folders: right-click any file or folder and select "Share." You can share via a direct link (viewable by anyone with the link, or restricted to specific email addresses) or invite specific people by email, choosing whether they can view only or also edit.

Version history: Nimbus automatically saves previous versions of every file for 30 days on the Free and Pro plans, and 180 days on the Team plan. To restore an earlier version, right-click the file, select "Version History," and choose the version you'd like to restore — this creates a new current version without deleting the more recent one.

Offline access: on both desktop and mobile apps, you can mark specific files or folders as "Available Offline," which downloads a local copy that stays in sync automatically whenever you're back online. This is useful for files you need to access while traveling or in areas with poor internet connectivity.

Collaborative editing: documents, spreadsheets, and presentations created within Nimbus support real-time collaborative editing, similar to Google Docs — multiple people can edit the same file simultaneously, and you'll see each person's cursor and changes live.

Search: Nimbus search looks inside file contents, not just filenames, for documents, spreadsheets, and PDFs. This means searching for a specific phrase can find it even if it's buried inside a 50-page document, not just in the title.

Mobile app features: the Nimbus mobile app (iOS and Android) supports camera upload (automatically backing up photos as you take them), document scanning (turning a photo of a paper document into a searchable PDF), and full file browsing and sharing identical to the desktop experience.

Integrations: Nimbus connects with Slack (get notified when files are shared with you), Zoom (attach Nimbus files directly to meeting invites), and Zapier (build custom automations connecting Nimbus to hundreds of other apps) — all available under Account Settings > Integrations.
